Developer Prompt — Sara Abdallah Website (2-Page Premium Personal Brand Site)
You are building a premium 2-page personal brand website for Sara Abdallah, a PhD-trained financial consultant and founder.
This is not a generic consultant website, not a CV site, and not a course-creator page.
The purpose of the site is to position Sara as a strategic financial authority for founders and SMEs, while keeping the experience modern, editorial, highly readable, and conversion-aware.
Core positioning
Sara helps founders and SME leaders turn messy financials into clear, confident business decisions.
She should feel:
• strategic 
• practical 
• calm 
• premium 
• intelligent 
• approachable without losing authority 
Do not make the site feel:
• robotic 
• corporate-heavy 
• fintech-generic 
• startup-template-ish 
• overly playful 
• overly dark or intimidating 
• like a dashboard SaaS product 

Site Structure
Only 2 pages:
1. Home 
2. Portfolio 

Design Direction
Use a premium editorial finance aesthetic.
Visual goals:
• clean hierarchy 
• sharp typography 
• spacious sections 
• strong readability 
• subtle confidence 
• restrained motion 
• clear section rhythm 
• excellent mobile experience 
Recommended mood:
• modern 
• elegant 
• structured 
• calm authority 
Think:
editorial personal brand + premium advisory + conversion-aware layout
Not:
agency template
Not:
fintech landing page cliché
Not:
generic corporate consulting site

Visual Style Guidelines
Layout
• Use generous whitespace 
• Strong section spacing 
• Clean grid system 
• Bento-style sections where useful, but don’t overdo it 
• Break content into digestible visual blocks 
• Avoid long uninterrupted text walls 
Typography
• Sophisticated, highly readable type hierarchy 
• Large confident headlines 
• Comfortable paragraph width 
• Strong contrast between headings, body, and microcopy 
• Make the text feel premium and easy to scan 
Components to use
• hero with strong message hierarchy 
• credibility strip 
• feature cards 
• proof/stat blocks 
• ecosystem/brand support section 
• case study cards or panels 
• CTA blocks 
• elegant footer 
Motion
• subtle only 
• soft fade / reveal / rise 
• no flashy animations 
• no gimmicks 
• no over-animated counters 
• motion should support clarity, not distract from it
